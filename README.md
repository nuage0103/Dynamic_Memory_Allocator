## 프로젝트 개요
**Dynamic Memory Allocator**는 C 프로그래밍에서 사용되는 동적 메모리 관리 기능을 직접 구현하는 프로젝트입니다. 표준 라이브러리 함수 대신 힙 영역을 직접 관리하는 메모리 할당기를 구현하며, **explicit free list** 기반 메모리 관리 구조를 사용하여 효율적인 메모리 할당과 해제를 수행합니다.

---

## 주요 기능
- **malloc**: 요청된 크기 이상의 메모리 블록을 힙 영역에서 탐색하여 할당합니다.
- **free**: 메모리 블록을 해제하고 free list에 추가합니다. 인접한 가용 블록이 존재할 경우 **boundary tag 구조 기반 coalescing**을 수행하여 외부 단편화를 줄입니다.
- **realloc**: 기존 메모리 블록의 크기를 변경합니다. 기존 블록의 크기가 충분한 경우 재사용하고, 그렇지 않은 경우 새로운 블록을 할당합니다.

---

## 프로젝트 구성

### 주요 함수
1. **mm_init()**: 초기 힙 영역을 설정하고 프롤로그와 에필로그 블록을 생성하여 힙 구조를 초기화합니다.
2. **mm_malloc(size_t size)**: free list에서 요청된 크기의 가용 블록을 탐색하여 할당합니다.
3. **mm_free(void *ptr)**: 할당된 메모리 블록을 해제하고 free 상태로 변경한 뒤, 인접 블록과 병합합니다.
4. **mm_realloc(void *ptr, size_t size)**: 기존 메모리 블록의 크기를 변경합니다. 기존 블록의 크기가 충분하면 재사용하고, 그렇지 않은 경우 새로운 블록을 할당한 뒤 데이터를 복사합니다.

### 서브 루틴 함수
1. **extend_heap(size_t words)**: `mem_sbrk()`를 호출하여 지정된 크기만큼 힙 영역을 확장하고, 새로 확보된 메모리 블록을 free list에 추가합니다.
3. **coalesce(void *ptr)**: 해제된 블록과 인접한 가용 블록을 병합하여 **외부 단편화**를 줄입니다.
4. **find_fit(size_t size)**: free list를 순회하며 요청된 크기에 맞는 가용 블록을 탐색합니다.
5. **place(void *ptr, size_t size)**: 지정된 주소의 가용 블록에 메모리를 할당합니다. 블록 크기가 충분한 경우 **block splitting**을 수행하여 남은 공간을 free list에 추가합니다.

## 컴파일 및 실행 방법
1. **컴파일**
```
make
```

2. **실행**: `trace` 파일을 기반으로 메모리 할당기의 성능 평가
```
./mdriver
```
